# ADR-017: Legacy Thin-Client FFI Integration (Archived)

## Status
Superseded (2026-01-18)

## Resolution

The former multi-language thin-client architecture was retired on January 18, 2026. All related code, FFI bindings, and supporting documentation were archived alongside the legacy workspace. Communitas now ships an all-Rust user experience built with Dioxus + Tauri 2 per ADR-020, so this ADR remains only as a historical reference in version control.

No active workflows, docs, or code paths reference the retired FFI layer, and any remaining artifacts live under `archive/` for posterity.
