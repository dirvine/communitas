# Communitas Desktop Production Deployment Guide

## Overview

This guide covers deploying Communitas Desktop for production use with self-updating capabilities and real network testing.

## Prerequisites

### Environment Setup
- **Rust**: 1.85+ with stable toolchain
- **Node.js**: 20+ with npm
- **Code Signing Certificates**: 
  - macOS: Apple Developer Certificate
  - Windows: Code Signing Certificate
- **GitHub Repository**: Access to `saorsalabs/communitas`

## Production Configuration

### 1. Update Endpoints
✅ **COMPLETED**: Update endpoints in `tauri.conf.json`:
```json
"endpoints": [
  "https://github.com/saorsalabs/communitas/releases/latest/download/latest.json"
]
```

### 2. Environment Variables
Set these for production builds:

```bash
# macOS Code Signing
export TAURI_MACOS_SIGNING_IDENTITY="Developer ID Application: Your Name"

# Windows Code Signing
export TAURI_WINDOWS_CERTIFICATE_THUMBPRINT="YOUR_CERT_THUMBPRINT"

# Update Public Key (generated by Tauri)
export TAURI_UPDATER_PUBKEY="dW50cnVzdGVkIGNvbnRlbnQ="

# Network Configuration (optional, defaults to config/production-network.toml)
export COMMUNITAS_NETWORK_CONFIG="config/production-network.toml"

# Optional: Environment-specific settings
export COMMUNITAS_ENV="production"  # or "staging", "development"
```

**Note**: NAT traversal uses native QUIC hole punching and relay capabilities built into ant-quic. No external STUN/TURN servers required.

### 3. Bootstrap Nodes for Real Testing
Add production bootstrap nodes to `network.rs`:

```rust

    vec![
        "ocean-forest-moon-star".to_string(),
        "river-mountain-sun-cloud".to_string(),

```
